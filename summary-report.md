Shared Responsibility Model

The Shared Responsibility Model explains how security and management tasks are divided between Microsoft Azure and the customer.

Microsoft Azure Responsibilities

Microsoft is responsible for:

Physical security of data centers
Hardware maintenance
Network infrastructure
Host operating systems
My Responsibilities as the Customer

I am responsible for:

Managing access and identities
Configuring security settings
Protecting my application data
Monitoring resource usage
Example Applied to My Deployment

For my Resource Group deployment:

Azure secures the physical infrastructure.
I manage permissions, configurations, and costs associated with the resources.
